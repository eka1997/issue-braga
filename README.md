# ISSUE Perfume Store — Viewer 3D + Gambar Kerja DED

- `index.html` – viewer 3D online (three.js), klik furnitur/dinding/pintu/lantai/plafon untuk membuka gambar kerja unit tersebut; menu "Gambar kerja…" berisi semua lembar DED (Rev.05).
- `offline.html` – versi offline satu file (tanpa internet).
- `model.glb`, `tex/`, `gk/` – model 3D, tekstur, dan gambar kerja (JPG).
